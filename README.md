# LUTIFY — Legal & Discord Verification Portal

Public documentation portal hosting official Terms of Service and Privacy Policy documentation for the LUTIFY Discord Application.

## Endpoints

- **Terms of Service:** `terms.html`
- **Privacy Policy:** `privacy.html`
- **Verification Dashboard:** `index.html`

## Discord Developer Portal Configuration

To configure verification links in the Discord Developer Portal:

1. Open your application in the [Discord Developer Portal](https://discord.com/developers/applications).
2. Go to **General Information**.
3. Under **Terms of Service URL**, paste your deployed `terms.html` link.
4. Under **Privacy Policy URL**, paste your deployed `privacy.html` link.
5. Click **Save Changes**.

## GitHub Pages Deployment

To enable GitHub Pages hosting:

1. Navigate to repository **Settings** &gt; **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Set the branch to `main` and folder to `/ (root)`.
4. Click **Save**.
